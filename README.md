# ContinuityIns-Frontend


## 预计功能特性

- **博客撰写和分享**：分享工作经验或者生活感悟，对感兴趣的话题进行讨论！。
- **文件上传和下载**：轻松上传与下载文件，无缝体验。

## 快速开始

按照以下步骤，本地运行：

1. **克隆仓库**

   ```bash
   git clone https://github.com/Owl23007/SSWeb.git
   cd SSWeb

2. **安装依赖**

   使用 npm 安装必要的依赖包：

   ```bash
   npm install
   ```

3. **启动项目**

   启动开发服务器：

   ```bash
   npm start
   ```
